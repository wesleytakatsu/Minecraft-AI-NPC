# Minecraft AI NPC

An AI-powered NPC companion mod for Minecraft Java Edition, built with Fabric.

## Overview

Minecraft AI NPC aims to bring intelligent companions into Minecraft. These companions will be able to communicate with players through chat, understand natural language commands, and perform real in-game tasks autonomously.

The project combines Large Language Models (LLMs), structured AI decision-making, and deterministic Minecraft automation systems.

## Planned Features

- Natural language communication through Minecraft chat
- AI-assisted command interpretation
- Autonomous navigation and player following
- Mining and tunnel excavation
- Tree cutting and resource gathering
- Inventory and chest management
- Item crafting and resource planning
- Combat and player protection
- Task management and progress tracking
- Persistent NPC memory and configurable behavior

## Technology

- **Minecraft:** Java Edition 1.20.1
- **Mod Loader:** Fabric
- **Language:** Java 17
- **AI:** LLM integration and JEV for structured decisions
- **Automation:** Server-side NPC control and pathfinding

## Development Status

🚧 **Early development / Planning phase**

The first milestone focuses on spawning a controllable NPC, interacting through chat, following the player, and completing basic excavation tasks.

Features listed above are planned and are not yet available.

## Roadmap

- **v0.1:** NPC spawning, chat interactions, following and basic tunneling
- **v0.2:** Resource gathering and inventory management
- **v0.3:** Crafting and resource planning
- **v0.4:** Advanced mining and exploration
- **v0.5:** Combat and survival
- **v0.6:** Smarter hostile mobs
- **v0.7+:** Advanced autonomy, memory and complex missions
